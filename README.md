# Thinkbot

A Java Swing-based desktop chatbot that learns from user interactions using a custom API and MySQL.

## Installation

```bash
# Java projects
mvn install            # If using Maven
# OR
gradle build           # If using Gradle
```

1. Clone the repository.
2. Open in your preferred Java IDE (IntelliJ IDEA, Eclipse, etc.).
3. Make sure MySQL is installed and running.
4. Configure database connection parameters in the source code as needed.
5. Build and run the project.

## Features
- Real-time chat
- User authentication
- Personalized history
- Adaptive GUI for contextual responses
